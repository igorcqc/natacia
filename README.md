# Natácia Duarte — Advocacia Previdenciária

Landing page de demonstração comercial para apresentação de proposta de site.

## Estrutura
- `index.html` — marcação e conteúdo
- `css/style.css` — estilos (paleta e tipografia da identidade visual)
- `js/main.js` — menu mobile, formulário (demo) e ano do rodapé
- `assets/img/` — adicionar aqui as fotos oficiais:
  - `natacia-duarte.jpg` (foto do Hero, proporção 4:5)
  - `natacia-duarte-2.jpg` (foto da seção "Sobre", proporção 4:5)

Enquanto as fotos reais não forem adicionadas, a página exibe um placeholder
com as iniciais "ND" automaticamente.

## Dados de exemplo
Telefone, e-mail e número da OAB usados no site são **fictícios** e devem
ser substituídos pelos dados reais antes da publicação.

## Como visualizar
Basta abrir `index.html` em um navegador, ou servir a pasta com qualquer
servidor estático (ex: `python3 -m http.server`).
